## Запуск для разработки

```bash
cp .env.example .env
make dev        # = docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```

Hot reload включён и для бэка, и для фронта. Первый запуск скачивает модель (~2 ГБ).

## Правила работы с git

- `main` всегда должна запускаться. Работаем в ветках `feat/<коротко>` и вливаемся через PR или быстрый merge после проверки.
- Новую страницу выносим из `pages/stubs.tsx` в свой файл и меняем импорт в `App.tsx`. Это единственные общие файлы, конфликты в них решаются за минуту.
- Новые строки интерфейса добавляем в оба словаря `i18n/index.tsx`.
- Тип ответа API поменялся? Обновляем `frontend/src/api/types.ts`.
- Перед пушем: `pytest -q` в `backend` и `npm run build` во `frontend`.
