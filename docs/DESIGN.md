# Дизайн кабинета Jana Hub

Страница входа не менялась. Всё, что после входа, живёт внутри `.app-shell` (`Layout.tsx`).

**Идея.** Jana Post — логистика. Тёмно-зелёный «лесной» сайдбар и почтовый жёлтый акцент.
На главной сотрудник видит свой пропуск в виде почтовой накладной со штрихкодом (`EmployeePass.tsx`),
а каждая заявка показана как трекинг посылки: Подана → Руководитель → HR → Оформлено (`RouteTrack.tsx`).

**Цвета** (`src/index.css`, классы Tailwind):
- `bg-forest` #0f3a22 — сайдбар, герой, основные кнопки; `bg-forest-2` — поверхности на тёмном
- `bg-signal` #f2c230 — акцент, активный пункт меню, «в пути»
- `bg-paper` #edf0e8 — фон; карточки белые, скругление 24px, без рамок и теней
- `text-ink` / `text-muted` — текст; `brand-600` — «оформлено»; `danger` — «отклонено»

**Шрифты** (локально, есть казахские буквы): `font-display` (Unbounded) — заголовки и крупные числа, Onest — остальное.

**Компоненты** (`components/ui.tsx`): `Card`, `PageHeader`, `buttonClass("primary" | "secondary")` для кнопок-ссылок,
`StatusBadge`, `ProgressBar`, `Empty`, `pluralRu()`. Списки заявок — `RequestRow` (`showEmployee` для руководителя/HR).
